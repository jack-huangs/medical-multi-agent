## 下一步

1. 建立覆盖冻结 30 道题的统一开放医学语料，保留来源与许可，人工检查检索覆盖。不能把本次单篇睡眠综述用于所有医学问题后解释其结果。
2. 固定模型推理模式、统一输出预算及失败处理规则，先预估 30 题费用。基础四组与单 Agent 对照最多 780 次请求，尚未启动。
3. 跑 30 题开发实验，检查错误共识频率、由对变错/由错变对、成本和简单去重是否已足够。
4. 若信号值得继续，重点加入改写传播、跨 Agent 继承和隐藏来源；分别评价已知来源上界与实际来源依赖识别。补充严格 token 预算、长度/位置对照及消融后再做正式验证。

完整设计、边界与命令见 [实验协议](evidence-dependency-protocol.md)。当前实现只支持来源已知的复制处理，尚未解决自动识别隐含依赖或验证医学蕴含的问题。
