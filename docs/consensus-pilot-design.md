# 医疗多智能体证据依赖预实验：高正确率情况下的设计

日期：2026-09-23。状态：设计与开发样本已准备，尚未执行新的模型实验。

## 当前证据

- 本地 `data/medqa/train.jsonl` 有 10,178 条，`test.jsonl` 有 1,273 条。
- 当前找到的 `external/MDAgents/output/advanced_result.json` 只有 1 个样本，输出 B 与标签 B 一致。这不代表历史只运行过一题，也不能估计总体正确率。
- 当前主程序按模式写入固定结果文件名，会覆盖旧结果；抽题未固定种子，不适合直接开展方法间配对比较。
- 正式基线比较前，需要修正中级流程意见写回与提前退出时空汇总的问题。修复属于基线维护，不计作算法创新。

## 样本量的含义

假设题目有相同的错误概率，200 道题在正确率 90%、95%、98%、99% 时，期望错误数分别为 20、10、4、2。这是期望值，不是保证。

在独立同分布近似下，99% 正确率对应 200 题全部答对的概率约 13.4%。因此零错误也不能证明方法没有问题。若关注的是“所有 Agent 一致且错误”，该事件还可能比最终错误更罕见。

100–200 题用于检查流程、测量成本、估计失败频率和观察效应方向，不作为论文最终优越性结论的充分样本量。正式规模根据配对结果中“旧方法错新方法对”与反方向的频率、目标效应和预定统计功效确定。

## 已准备的开发样本

运行 `scripts/prepare_consensus_pilot.py` 可以从本地训练集生成固定样本，种子为 20260923。脚本不导入模型 SDK、不读取密钥、不调用 API。

- `pilot_100`：首批 100 题，用于开发摸底。
- `reserve_200`：额外 200 题，用于有需要时按预先声明的规则扩展开发实验。
- `demonstrations_5`：与前两组分离的 5 道示例题。
- 官方测试集不用于这次方案调参；生成时只读取它检查精确重叠。
- 输入和答案分别保存。只有评分器可以读取 pilot/reserve 的 labels 文件。示例题的答案可以作为 few-shot 上下文。
- 保存原始数据 SHA-256、样本 ID 和原始行号；排除规范化题干与选项完全重复的条目。语义近重复及预训练污染仍未排除。
- 输出位于 `runs/consensus_pilot_20260923/`，已被仓库现有忽略规则覆盖。

当前主程序尚未接入该清单；不得直接执行现有随机抽样命令并称其为固定清单实验。

## 分开的三个评测问题

1. 常规表现：在预先固定的完整样本上报告准确率、解析失败率、成本和置信区间。
2. 困难场景：使用独立定义的困难基准，例如 MedicalAgentsBench 或 MedXpertQA-Text，并单独报告；不能把筛出的错题准确率说成总体准确率。
3. 机制稳健性：对同一题实施证据复制、转述和来源标记干预，比较答案与置信度变化。保留原本答对和答错的题，不根据新方法结果选择样本。

困难子集如由当前模型筛选，限用于开发分析；正式验证使用未参与筛选的新样本，并报告筛选机制。不能为了制造错误故意削弱模型或删掉诊断所需信息后仍使用原标签。

## 最小机制实验

先在固定基线上增加可追溯的普通 RAG，再研究来源依赖；当前纯讨论基线尚不能直接用于验证外部证据重复的问题。

每道题从相同初始状态出发，比较原始证据、重复证据、重复证据加简单去重，以及依赖感知处理。保留对照中的关键证据，控制文本长度、位置、token 预算，记录重复内容是否挤占其他检索结果。分别分析检索阶段挤占与讨论阶段重复传播的效应。

主要记录：

- 最终正确率；由对变错、由错变对的配对计数。
- 全员共识且错误的样本数/全部样本数，以及错误共识数/共识样本数；保留分母，共识样本数为零时报告不适用。
- 重复信息下置信度的变化；未经验证的模型自报置信度仅作行为信号。
- 调用次数、token、耗时；所有验证与检索开销计入。
- 同一题的不同干预不能当作独立新病例；推断按原始题目分组。

准确率不变但置信度变化可以支持行为分析，不能直接证明临床获益。证据一致性改善也不能代替最终任务评价。

## 扩展与停止

首批完成后，只在开发集上确定下一阶段规模和方法。若错误过少，优先增加独立困难基准、扩大预先固定的开发样本；若结果仍不明确，报告不确定性，不反复追加样本直到出现显著性。

正式研究冻结协议后使用留出的测试数据。若简单去重或同预算单 Agent 已解释全部收益，就应收窄主张或改变研究切口。

## 文献

- [MedicalAgentsBench，2026 年修订版](https://arxiv.org/abs/2503.07459v3)：862 个经过难度筛选的复杂问题；与其他医学数据集可能重叠，应做跨集合去重。论文中历史模型成绩不能代替本项目实测。
- [MedXpertQA](https://arxiv.org/abs/2501.18362)：含 Text 和 MM 子集，首阶段只考虑文字子集；公开可访问不等于没有预训练污染。
- [Correlated Errors in Large Language Models](https://arxiv.org/abs/2506.07962)：通用错误相关性研究，需要与医疗检索证据重复机制区分。
